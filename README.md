# Boran Zhang Homepage

Personal academic homepage for **Boran Zhang**.

The site is built with Jekyll and GitHub Pages, based on the AcadHomepage template.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://127.0.0.1:4000>.

## Main Content Files

- `_pages/about.md`: homepage content.
- `_config.yml`: site title, author profile, links, and SEO description.
- `_data/navigation.yml`: top navigation.
- `images/`: favicon, avatar, and publication figures.
